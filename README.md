# Bottom — крипто-ресерчер в Telegram

ИИ-агент, которому трейдер задаёт вопросы о крипте: разбор монеты, деривативы, стаканы всех бирж,
спреды и фандинг рынка, Binance Alpha, DEX и безопасность контракта, новости и слухи, X и
Telegram-каналы (вместе с картинками авторов), сетапы с проверенным расчётом. Сопоставляет источники
между собой и с ценой и учится на своих ошибках. Сигналы сам не публикует — отвечает на вопрос.

```
вопрос → модель выбирает, какие данные нужны → инструменты собирают данные
       → модель пишет разбор → цифры сверяются с данными, сетап проходит валидатор → ответ
```

Принцип: **код считает, модель объясняет.** Цифры в ответе берутся только из инструментов и
проверяются кодом; вход, стоп и R:R модель показывает только после вердикта валидатора `calc_setup`.

## Что умеет

| Задача | Инструменты | Откуда данные |
|---|---|---|
| Цены спот и фьючерсов на всех биржах, базис, разброс, «тот ли это токен» | `market_overview`, `resolve_token` | 10 бирж через ccxt (Binance, Bybit, OKX, Bitget, Gate, MEXC, KuCoin, BingX, Hyperliquid, Aster), CoinGecko |
| Графики: свечи 1m–1d, EMA/RSI/Stoch/ATR/MACD/Боллинджер, уровни и их тесты, Фибоначчи, дельта и CVD | `candles` (`market`: auto / perp / spot / alpha) | Binance (с taker-объёмом), любая биржа, Binance Alpha |
| Стаканы **всех бирж разом**: сводная глубина ±1/2/5%, у кого глубина, крупнейшие стенки рынка | `orderbook` (без `exchange` — все биржи) | 10 бирж; для Alpha — ликвидность DEX-пулов |
| **Binance Alpha**: токен (цена, объём, ликвидность, холдеры, контракт) или рынок Alpha (топ, движения, листинги) | `binance_alpha` | binance.com Alpha API |
| Фандинг по 13 биржам и спреды фьюч↔фьюч по 12 биржам | `funding_rates`, `awtrader_spreads` | [awtrader.com](https://awtrader.com) |
| Спред одной монеты в деталях: фьюч↔фьюч, спот↔фьюч (CEX и DEX), индексы, сколько держится, ёмкость стаканов | `spread_check` | биржи + DexScreener + GeckoTerminal |
| Деривативы и OI: фандинг, OI и его динамика, L/S, taker flow, кто ведёт — спот или перп, карточка OI по методичке | `derivatives`, `oi_card`, `spot_perp_flow` | Binance, Bybit, OKX, Aster |
| Депозиты и выводы по сетям, конфликты контрактов | `transfer_status` | Binance, Gate, KuCoin, Bitget (+ Bybit/OKX/MEXC/BingX с read-only ключом) |
| DEX, мемы, контракт, DeFi, киты в пуле, фон рынка | `dex_pairs`, `token_security`, `token_fundamentals`, `defi_protocol`, `dex_whales`, `market_sentiment` | DexScreener, GeckoTerminal, GoPlus, CoinGecko, DefiLlama, alternative.me |
| **Гуглить**: поиск в интернете и чтение страниц | `web_search`, `fetch_page` | Tavily → Brave → DuckDuckGo (без ключей); Jina Reader |
| **X (Twitter)** без платного ключа: аккаунты, поиск, отслеживаемые ленты | `x_posts` | twitterapi.io (ключ) → зеркала Nitter → лента X для встраивания → поиск `site:x.com` |
| **Telegram-каналы** из списка: упоминания тикера, что обсуждают, лента канала целиком, картинки | `telegram_channels`, `analyze_image` | твой аккаунт Telegram |
| OI-алерты Ultra (OVERTAKE) из каналов: серии по монете, паттерн и красные флаги | `ultra_alerts` | Telegram |
| Крипто-СМИ и проверка новости по всем источникам: кто первый, копии или подтверждения, реакция цены | `crypto_news`, `cross_check` | RSS (CoinDesk, Cointelegraph, The Block…), CryptoPanic, Telegram, X, интернет |
| Сетапы: проверка и расчёт, своя статистика, колы референсного колера с исходами | `calc_setup`, `track_record`, `reference_calls` | свой код и журнал |

X, каналы и СМИ — это новости и мнения, а не цифры рынка: цены, OI и фандинг бот берёт только с бирж.

## Как устроено

```
bottom/
  app.py           сборка бота: настройки → Telegram-сборщик → инструменты → модель → агент → бот
  __main__.py      одна точка входа: python -m bottom [check|tg|selftrain|reference|claude|mcp]
  config.py        настройки из .env
  agent/           ограниченный цикл агента, правила (prompts), примеры, проверка чисел (grounding)
  llm/             модели: API (OpenAI-совместимые, Anthropic), запасная модель, agy, Claude Code
  bot/             Telegram-бот: чаты и группы, статусы, Telegram HTML, память диалогов, лимиты
  tools/           инструменты — реестр и домены, каждый регистрирует свои инструменты:
    market/          биржи, Binance Alpha, стаканы, свечи и индикаторы, деривативы, OI, спреды, фандинг, переводы
    onchain/         токены и фундаментал, DEX, безопасность контракта, DeFi, киты в пулах
    social/          Telegram-каналы, X, СМИ, алерты Ultra, сопоставление источников
    web.py           поиск в интернете и чтение страниц
    setups/          валидатор сетапов, своя статистика, колы референса
  tg/              чтение Telegram через твой аккаунт: вход, проверка источников, живой сбор, база сообщений
  learning/        журнал сетапов, оценка исходов, уроки, референсный колер, самообучение
  vision.py        разбор картинок
  mcp_server.py    все инструменты как MCP-сервер для Claude Code
  check.py         проверка настроек и живая проверка каждого источника
channels/          sources.json — публичные каналы; private.json — твои приватные (только локально)
windows/           .bat для запуска на Windows двойным кликом
```

## Модель: три режима

Выбирается одной строкой `LLM_PROVIDER` в `.env`. Инструменты, валидатор, проверка чисел и журнал
одинаковы во всех режимах.

| Режим | `LLM_PROVIDER` | Что нужно | Когда брать |
|---|---|---|---|
| **Gemini по подписке** (метод [agy-gemini-mcp](https://github.com/velime/agy-gemini-mcp)) | `agy` | Google AI Pro, Antigravity CLI, вход в `agy` | бесплатно сверх подписки; личка и небольшой чат. Медленно: каждый раунд инструментов — отдельный запуск `agy` |
| **API** | `openai` или `anthropic` | ключ (Gemini AI Studio, OpenRouter, Claude API) | быстро; большой чат; запасная модель для двух других режимов |
| **Claude Code (MCP)** | `claude_code` | подписка Claude, Claude Code | качество разборов на подписке; Claude сам вызывает инструменты через MCP |

Рекомендуемая связка: основной — `agy` или `claude_code`, запасной (`FALLBACK_LLM_*`) — API. Упёрлась
подписка в лимит, не пустил регион или модель вернула пустоту — тот же вопрос продолжает запасная.

- **agy.** На каждый вопрос — папка в `agy_workspace/` с `TASK.md` (правила, инструменты со схемами,
  протокол ответа, разговор, вопрос). Gemini отвечает JSON: `{"calls": [...]}` или `{"answer": "..."}`;
  инструменты вызывает, цифры проверяет и сетапы валидирует сам бот (`bottom/llm/agy.py`). `agy`
  работает с автоподтверждением (иначе в фоне он не прочитает `TASK.md`) — запускай бота от
  пользователя без доступа к важным файлам. Antigravity доступен не во всех странах.
  Настройки: `AGY_PATH`, `AGY_EFFORT` (`low`), `AGY_TIMEOUT_MIN` (5); общий лимит на ответ — 15 минут.
- **Claude Code.** `windows\claude_setup.bat` ставит Claude Code и готовит `claude_workspace/`: правила
  в `CLAUDE.md`, одно подключение ко всем инструментам (`.mcp.json` → MCP-сервер `bottom.mcp_server`), права
  только на чтение. `windows\claude_chat.bat` — разговор с Bottom в терминале (бот-токен не нужен);
  `LLM_PROVIDER=claude_code` + `start.bat` — Telegram-бот отвечает через Claude Code.
- **API.** По умолчанию — бесплатный Gemini Flash (ключ: <https://aistudio.google.com/apikey>), запасной —
  бесплатная модель OpenRouter с инструментами. Claude API: `LLM_PROVIDER=anthropic`, `LLM_API_KEY`,
  `LLM_MODEL`.

## Быстрый старт

**Windows** — пошагово в [`docs/windows.md`](docs/windows.md): `windows\install.bat` → `windows\check.bat` →
`windows\tg_login.bat` → `windows\start.bat`.

**Любая система** (Python 3.11+):
```bash
python -m venv .venv && source .venv/bin/activate
pip install -e .
cp .env.example .env          # впиши TELEGRAM_BOT_TOKEN и модель (раздел «Модель»)
python -m bottom check        # настройки и живая проверка каждого источника
python -m bottom tg login     # вход в свой Telegram для чтения каналов (один раз)
python -m bottom              # бот
```
Docker: `docker build -t bottom . && docker run --env-file .env -v $(pwd)/data:/data bottom`
(вход в Telegram: `docker run -it --env-file .env -v $(pwd)/data:/data bottom python -m bottom tg login`).

`python -m bottom check` запрашивает у каждого источника маленький реальный ответ: 11 бирж,
Binance Alpha, awtrader, каждое зеркало Nitter и ленту X, поиск, чтение страниц, RSS, CoinGecko,
DexScreener, DefiLlama, модели и бота. Источник, закрытый из твоей сети, будет виден сразу.

## Telegram-каналы

Все источники читаются через **твой аккаунт** (Telethon): новые сообщения приходят вживую, история —
за `TG_BACKFILL_DAYS` дней (0 — весь канал), пропущенное догружается раз в `TG_RESYNC_MINUTES`,
картинки разбирает модель со зрением.

- `channels/sources.json` — **публичные каналы**, часть репозитория (161).
- `channels/private.json` — **твои приватные** каналы и чаты, только на твоём компьютере (в `.gitignore`).
  Читаются вместе с публичными; каждый источник сохраняется в свой файл; новые из аккаунта
  (`scan --include-dialogs`) попадают в приватный.
- Свои прежние приватные источники верни одной командой: `python -m bottom tg restore-private`
  (или `windows\restore_private.bat`) — возьмёт их из прежнего общего списка в истории git.
- `python -m bottom tg scan` — один раз проверить, какие источники про крипту (отчёт `channels/report.md`,
  тоже только локально); `collect` — собирать без бота; `search BTC` — что собрано.
- Приватное остаётся приватным: такие сообщения бот использует как фон — не цитирует, не называет и не
  даёт ссылку (`TG_SHOW_PRIVATE=true` разрешает).

Файл `data/telegram.session` — полный доступ к аккаунту: никому не отправляй (он в `.gitignore`).

## X без платного ключа

`x_posts` читает аккаунты, ищет по тикеру или теме и смотрит отслеживаемые ленты (`X_ACCOUNTS`) через
первый источник, который ответил, и пишет, откуда пост (`via`):
1. **twitterapi.io** — если задан `TWITTERAPI_IO_KEY` (платно, надёжнее всего);
2. **зеркала Nitter** — бесплатный RSS; список — `X_NITTER_URLS`, упавшее зеркало пропускается 10 минут;
3. **лента X для встраивания** (syndication) — бесплатно, только аккаунты, может отставать;
4. **поиск `site:x.com`** — только заголовки и выдержки.

Публичные зеркала Nitter то работают, то нет: какие живы из твоей сети, покажет `python -m bottom check`.
Без ключа из отслеживаемых аккаунтов читаются первые 12.

## Обучение

- **Журнал и исходы.** Каждый выданный сетап записывается; раз в 30 минут по часовым свечам считается
  исход (не исполнился / стоп / TP1 → безубыток / TP2), R, MFE и MAE — консервативно: вход по худшему
  краю зоны, стоп и цель в одной свече — стоп.
- **Жалобы.** Ответ на разбор бота командой `/wrong что не так`.
- **Уроки.** Раз в сутки модель читает исходы и жалобы и пишет уроки со ссылками на случаи; ссылки
  проверяет код. Урок надо заслужить: кандидат применяется только после подтверждения разными случаями
  в разные дни или после `/adopt`; противоречие помечает урок спорным, а не удаляет; кандидат живёт
  30 дней, урок без подтверждений — 60, одновременно не больше 30.
- **Референсный колер.** `bottom/data/reference_calls.json.gz` — разобранные колы, наблюдения и
  обновления темы «Maga AI calls» (881 сообщение, 09.06–26.10.2026; уровни у 305, результаты людей у
  90). Колы проверяются по реальным свечам тем же оценщиком; статистика по типам идей идёт в блок
  «Опыт», похожие колы с исходами — `reference_calls`. Новая выгрузка темы:
  `python -m bottom reference import result.json` (повторы по id сообщения не дублируются).
- **Самообучение, разовый прогон.** `windows\selftrain.bat` (`python -m bottom selftrain --agy`):
  выгрузки из `references/` → исходы всех колов и своих сетапов по свечам → Gemini через `agy` разбирает
  закрытые колы пачками по 40 и пишет уроки со ссылками (`[R12, R40]`); урок активен, когда его
  подтверждают колы двух разных дней. Отчёт — `data/selftrain_report.json`. Повторный запуск продолжит
  с места остановки; если биржи не отвечают, прогон останавливается, ничего не портя.

## Защита от выдуманных цифр и зацикливания

- **Проверка чисел** (`bottom/agent/grounding.py`) — кодом: числа из ответа сверяются с данными
  инструментов, вопросом и правилами; много ненайденных — модель один раз переписывает ответ.
- **Валидатор** (`bottom/tools/setups/calc.py`): минимальный стоп по классу актива и ATR, минимальный
  R:R, потери по плечам, живая цена относительно плана, ликвидность сразу за стопом.
- **Границы:** бюджет шагов на вопрос, повторные вызовы из кеша, таймаут 60 с на инструмент и 5 минут
  на ответ (15 в режиме `agy`).

## В Telegram

- **Личка:** пиши вопрос обычным сообщением; можно прислать картинку (график, скрин) или переслать
  OI-алерт.
- **Группы:** добавь бота; он отвечает, если его упомянули через `@имя_бота` или ответили на его
  сообщение.
- **Команды:** `/start`, `/help` — FAQ · `/limit` — остаток шагов · `/reset` — очистить контекст ·
  `/wrong текст` — сообщить об ошибке · `/stats [тикер]` — статистика сетапов · `/lessons` — уроки ·
  `/lesson текст`, `/adopt N`, `/forget N` — управление уроками (админ из `ADMIN_IDS`).

Все — в `.env` (образец с пояснениями — `.env.example`).

## Разработка

```bash
pip install -e ".[dev]"
pytest
```
Тесты не ходят в сеть: биржи, Binance Alpha, X, поиск и CLI моделей (`agy`, `claude`) подменяются;
валидатор проверяется на реальных колах (опубликованные проходят, ошибочные сетапы из чатов
отклоняются). Новый инструмент добавляется в своём домене (`bottom/tools/<домен>/__init__.py`,
функция `register`): описание, JSON-схема аргументов, статус для пользователя и функция.
