# Запуск Swarm на Windows — пошагово

Всё делается двойным кликом по `.bat`-файлам. Командную строку знать не нужно.

## Шаг 1. Установи Python (один раз)

1. Открой <https://www.python.org/downloads/> → кнопка **Download Python 3.12** (или новее).
2. Запусти скачанный файл.
3. **Внизу окна установщика поставь галочку «Add python.exe to PATH»** — без неё ничего не заработает.
4. Нажми **Install Now**, дождись конца.

## Шаг 2. Скачай бота

1. Открой в браузере (нужно быть залогиненным в GitHub):
   <https://github.com/velime/RobinhoodDao/archive/refs/heads/claude/cool-brahmagupta-0vkcwx.zip>
2. Распакуй архив в простую папку **без русских букв и пробелов**, например `C:\swarm`.
   Внутри должны лежать `install.bat`, `start.bat`, папка `swarm` и т.д.

## Шаг 3. Получи ключи (один раз)

| Что | Где взять | Куда вписать |
|---|---|---|
| Токен бота | Telegram → [@BotFather](https://t.me/BotFather) → `/newbot` → придумай имя и username → скопируй токен вида `123456789:AAH...` | `TELEGRAM_BOT_TOKEN` |
| Ключ Gemini | <https://aistudio.google.com/apikey> → **Create API key** → скопируй | `LLM_API_KEY` |
| Модель Gemini | в <https://aistudio.google.com> открой список моделей и возьми последнюю `gemini-…-flash` | `LLM_MODEL` |
| Ключ OpenRouter | <https://openrouter.ai> → войти → <https://openrouter.ai/settings/keys> → **Create Key** | `FALLBACK_LLM_API_KEY` |

Для Telegram-каналов (можно позже):

| Что | Где взять | Куда вписать |
|---|---|---|
| api_id и api_hash | <https://my.telegram.org> → войти по номеру → **API development tools** → заполни форму (название любое) → скопируй **App api_id** и **App api_hash** | `TG_API_ID`, `TG_API_HASH` |

## Шаг 4. Установка

1. Двойной клик по **`install.bat`**. Подожди пару минут.
2. Откроется Блокнот с файлом `.env`. Впиши ключи после знака `=` без пробелов и кавычек, например:
   ```
   TELEGRAM_BOT_TOKEN=123456789:AAHxxxxxxxxxxxxxxxxxxxxxxxx
   LLM_API_KEY=AIzaSyxxxxxxxxxxxxxxxxxxxxxxx
   LLM_MODEL=gemini-…-flash
   FALLBACK_LLM_API_KEY=sk-or-v1-xxxxxxxxxxxx
   ```
3. Сохрани (**Ctrl+S**) и закрой Блокнот.

Если понадобится снова открыть настройки: правый клик по файлу `.env` → **Открыть с помощью** → **Блокнот**.

## Шаг 5. Проверка

Двойной клик по **`check.bat`**. Он проверит каждый ключ и напишет:
- ✅ — всё хорошо;
- ❌ — что не так и где взять правильное значение;
- ⚠️ — не обязательно, но стоит знать.

Исправь ❌ в `.env` и запусти `check.bat` ещё раз, пока не будет «Всё готово».

## Шаг 6. Telegram-каналы (по желанию)

1. **`tg_login.bat`** — вход в твой аккаунт (один раз). Введи номер в формате `+380…`,
   затем код — он придёт **в приложение Telegram** (чат «Telegram»). Если включён облачный
   пароль — введи и его. Появится файл `data\telegram.session` — **никому его не отправляй**,
   это доступ к аккаунту.
2. **`tg_scan.bat`** — один раз проверит каналы из `channels\all.txt` и оставит только
   крипто. В конце откроется отчёт `channels\report.md`. Если хочешь добавить в проверку и
   каналы, на которые подписан: открой командную строку в папке и выполни
   `tg_scan.bat --include-dialogs`.

## Шаг 7. Запуск

Двойной клик по **`start.bat`**. Пока окно открыто — бот работает. Напиши своему боту в
Telegram `/start`.

Чтобы бот работал круглосуточно, компьютер должен быть включён и не уходить в сон.
Когда всё заработает — можно перенести на сервер (VPS), подскажу как.

## Если что-то пошло не так

- **«python не является внутренней или внешней командой»** / «Python не найден» — Python
  установлен без галочки «Add python.exe to PATH». Переустанови с галочкой.
- **Окно мигнуло и закрылось** — запусти `.bat` ещё раз; если повторяется, сделай скриншот.
- **Бот молчит** — проверь `check.bat`; убедись, что пишешь именно своему боту.
- Любая другая ошибка — скопируй текст из окна и пришли.
