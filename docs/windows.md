# Запуск Bottom на Windows — пошагово

Всё делается двойным кликом по `.bat`-файлам из папки `windows`. Командную строку знать не нужно.

## Telegram-каналы без бота

Источники читаются через **твой аккаунт** — он в них уже состоит, вступать никуда не нужно:
- `channels\sources.json` — 161 публичный канал (часть проекта);
- `channels\private.json` — твои приватные каналы и чаты (только на твоём компьютере, в git не попадает).
  Прежние приватные источники возвращает **`windows\restore_private.bat`** — один раз, после обновления.

1. Установи Python — [шаг 1](#шаг-1-установи-python-один-раз) (галочка «Add python.exe to PATH»!).
2. Скачай и распакуй проект — [шаг 2](#шаг-2-скачай-бота).
3. **`windows\scan_channels.bat`** — один раз проверит каждый источник: крипта или нет. При первом
   запуске спросит:
   - **api_id** и **api_hash** — <https://my.telegram.org> → войти по номеру → **API development
     tools** → заполнить форму (название любое) → **Create application** → скопировать
     **App api_id** (цифры) и **App api_hash**. Вставить в окно — правый клик мышью.
     Спросит один раз, запомнит в `.env`;
   - **номер телефона** в формате `+380XXXXXXXXX`;
   - **код** — придёт в приложение Telegram, в чат «Telegram»;
   - **облачный пароль** — только если включён.

   В конце откроется отчёт `channels\report.md`. Некрипто-источники выключатся (`"enabled": false`),
   сомнительные останутся включены.
4. **`windows\tg_collect.bat`** — собирает сообщения: сначала читает историю за `TG_BACKFILL_DAYS`
   дней (по умолчанию 30, `0` — весь канал целиком), потом ловит новые сообщения сразу, как
   они появляются, и разбирает картинки (графики, скрины) моделью из `.env`. Пока окно
   открыто — сбор идёт.
   Проверить, что собралось: в командной строке в папке проекта
   `.venv\Scripts\python -m bottom tg search BTC`.

Повторные запуски ключи и код не спрашивают. Файл `data\telegram.session` — вход в твой
аккаунт, никому его не отправляй.

Хочешь добавить или убрать источник вручную — открой `channels\sources.json` (или `private.json`) в
Блокноте и поменяй `"enabled"` на `true`/`false` и `"manual"` на `true` (тогда проверка его не тронет).

## Шаг 1. Установи Python (один раз)

1. Открой <https://www.python.org/downloads/> → кнопка **Download Python 3.12** (или новее).
2. Запусти скачанный файл.
3. **Внизу окна установщика поставь галочку «Add python.exe to PATH»** — без неё ничего не заработает.
4. Нажми **Install Now**, дождись конца.

## Шаг 2. Скачай бота

1. Открой в браузере (нужно быть залогиненным в GitHub):
   <https://github.com/velime/RobinhoodDao/archive/refs/heads/claude/cool-brahmagupta-0vkcwx.zip>
2. Распакуй архив в простую папку **без русских букв и пробелов**, например `C:\bottom`.
   Внутри должны лежать папки `bottom`, `windows`, `channels`, файл `.env.example` и т.д.

## Шаг 3. Получи ключи (один раз)

| Что | Где взять | Куда вписать |
|---|---|---|
| Токен бота | Telegram → [@BotFather](https://t.me/BotFather) → `/newbot` → придумай имя и username → скопируй токен вида `123456789:AAH...` | `TELEGRAM_BOT_TOKEN` |
| Ключ Gemini | <https://aistudio.google.com/apikey> → **Create API key** → скопируй | `LLM_API_KEY` |
| Модель Gemini | в <https://aistudio.google.com> открой список моделей и возьми последнюю `gemini-…-flash` | `LLM_MODEL` |
| Ключ OpenRouter | <https://openrouter.ai> → войти → <https://openrouter.ai/settings/keys> → **Create Key** | `FALLBACK_LLM_API_KEY` |

Для Telegram-каналов (можно позже):

| Что | Где взять | Куда вписать |
|---|---|---|
| api_id и api_hash | <https://my.telegram.org> → войти по номеру → **API development tools** → заполни форму (название любое) → скопируй **App api_id** и **App api_hash** | `TG_API_ID`, `TG_API_HASH` |

## Шаг 4. Установка

1. Двойной клик по **`windows\install.bat`**. Подожди пару минут.
2. Откроется Блокнот с файлом `.env`. Впиши ключи после знака `=` без пробелов и кавычек, например:
   ```
   TELEGRAM_BOT_TOKEN=123456789:AAHxxxxxxxxxxxxxxxxxxxxxxxx
   LLM_API_KEY=AIzaSyxxxxxxxxxxxxxxxxxxxxxxx
   LLM_MODEL=gemini-…-flash
   FALLBACK_LLM_API_KEY=sk-or-v1-xxxxxxxxxxxx
   ```
3. Сохрани (**Ctrl+S**) и закрой Блокнот.

Если понадобится снова открыть настройки: правый клик по файлу `.env` → **Открыть с помощью** → **Блокнот**.

## Шаг 5. Проверка

Двойной клик по **`windows\check.bat`**. Он проверит каждый ключ и каждый источник данных
(биржи, Binance Alpha, awtrader, X, поиск…) и напишет:
- ✅ — всё хорошо;
- ❌ — что не так и где взять правильное значение;
- ⚠️ — не обязательно, но стоит знать.

Исправь ❌ в `.env` и запусти `check.bat` ещё раз, пока не будет «Всё готово». ⚠️ у источника
значит, что он не отвечает из твоей сети (блок по региону, упавшее зеркало Nitter) — бот возьмёт данные
из других.

## Шаг 6. Telegram-каналы (по желанию)

1. **`windows\tg_login.bat`** — вход в твой аккаунт (один раз). Введи номер в формате `+380…`,
   затем код — он придёт **в приложение Telegram** (чат «Telegram»). Если включён облачный
   пароль — введи и его. Появится файл `data\telegram.session` — **никому его не отправляй**,
   это доступ к аккаунту.
2. **`windows\scan_channels.bat`** — один раз проверит источники
   (подробности — [в начале](#telegram-каналы-без-бота)). Бот сам начнёт собирать сообщения
   при запуске `start.bat`.
3. **`windows\restore_private.bat`** — вернуть свои приватные каналы и чаты (если ты пользовался
   ботом до разделения списка).

## Шаг 7. Запуск

Двойной клик по **`windows\start.bat`**. Пока окно открыто — бот работает. Напиши своему боту в
Telegram `/start`.

Чтобы бот работал круглосуточно, компьютер должен быть включён и не уходить в сон.
Когда всё заработает — можно перенести на сервер (VPS), подскажу как.

## Если что-то пошло не так

- **«python не является внутренней или внешней командой»** / «Python не найден» — Python
  установлен без галочки «Add python.exe to PATH». Переустанови с галочкой.
- **Окно мигнуло и закрылось** — запусти `.bat` ещё раз; если повторяется, сделай скриншот.
- **Бот молчит** — проверь `check.bat`; убедись, что пишешь именно своему боту.
- Любая другая ошибка — скопируй текст из окна и пришли.

## Все скрипты (папка `windows`)

| Файл | Что делает |
|---|---|
| `install.bat` | установка и открытие `.env` |
| `check.bat` | проверка ключей и каждого источника данных |
| `start.bat` | Telegram-бот |
| `tg_login.bat`, `scan_channels.bat`, `tg_collect.bat` | вход в Telegram, проверка источников, сбор без бота |
| `restore_private.bat` | вернуть приватные каналы в `channels\private.json` |
| `claude_setup.bat`, `claude_chat.bat` | Bottom в Claude Code на подписке Claude |
| `selftrain.bat` | разовое самообучение через `agy` (можно перетащить на него `result.json`) |
